# 2026-09-13 Closet Index Development Log

## Work Summary

Outfit 수정 화면에서 긴 Item 추가 목록 때문에 평가와 이름 수정 영역을 찾기 어려운 문제를 해결하기 위해 화면 섹션 순서를 조정했다.

## Work Completed

- Outfit 수정·등록 화면의 순서를 `현재 선택 → 배치 조정 → 이름과 저장 검토 → Item 추가`로 변경했다.
- 기존 rating 선택, 이름 수정, Item 재선택, 고정 저장 버튼의 동작은 유지했다.
- 저장 검토 영역이 Item 추가 영역보다 먼저 렌더링되는지 확인하는 회귀 테스트를 추가했다.

## Decisions

- 데이터 요청량과 저장 계약에는 영향을 주지 않도록 JSX 섹션 위치만 이동했다.
- 수정과 등록이 같은 컴포넌트를 사용하므로 두 화면에서 동일한 정보 순서를 유지했다.

## Current Status

- Outfit Creator 관련 테스트 7개와 production build가 통과했다.
- 데스크톱 1616×882와 모바일 390×844에서 저장 검토가 Item 추가보다 먼저 렌더링되는 것을 확인했다.
- 평가 선택을 변경한 뒤 원래 값으로 되돌리는 상호작용을 확인했으며 브라우저 콘솔 오류·경고는 없었다.

## Next Steps

- 실제 서비스 반영을 위해서는 별도 커밋·푸시·배포가 필요하다.

## Work Summary - Top 이너웨어 추천 근거 제외

`Top-T-shirts-innerwear`는 Outfit을 구성하는 실제 Item이지만, 속옷 착용 이력이 새 Outfit의 온도 적합성을 뒷받침하는 핵심 근거가 되는 문제를 수정했다.

## Work Completed - Top 이너웨어 추천 근거 제외

- `Top-T-shirts-innerwear`를 추천 근거에서 제외하는 공통 카테고리 판정 함수를 추가했다.
- 새 Outfit의 핵심 Item 온도 근거, 기존 Item 근거 개수, 유사 Outfit의 공유 Item·변경 Item·가중 유사도 계산에서 해당 카테고리를 제외했다.
- Outfit 구성, Closet 표시, Wear Log와 기존 통계 데이터에는 영향을 주지 않았다.
- 이너웨어와 다른 핵심 Item에 각각 OK 기록이 있어도 이너웨어는 근거 수와 시험 추천 범위에 포함되지 않는 회귀 테스트를 추가했다.

## Decisions - Top 이너웨어 추천 근거 제외

- 카테고리를 삭제하거나 Top 그룹에서 분리하지 않고 추천 근거 계산 경계에서만 제외했다. 이 방식으로 기존 데이터와 Outfit 완성 조건을 유지했다.
- 대소문자와 앞뒤 공백은 정규화하되 정확한 `Top-T-shirts-innerwear`만 제외해 다른 Top 또는 독립 `Innerwear` 카테고리로 범위를 넓히지 않았다.
- Item 온도 근거와 유사 Outfit 근거가 서로 다른 기준을 사용하지 않도록 동일한 공통 판정을 적용했다.

## Current Status - Top 이너웨어 추천 근거 제외

- 관련 테스트 47개와 전체 테스트 649개가 통과했으며 production build도 성공했다.
- 로컬 데모 HOME에서 20°C 추천 결과를 데스크톱과 모바일 390×844로 확인했다.
- 모바일 가로 넘침이 없고 브라우저 콘솔 경고·오류가 없음을 확인했다.
- 운영 DB와 Supabase schema는 변경하지 않았으며 실제 운영 URL에는 아직 배포하지 않았다.

## Next Steps - Top 이너웨어 추천 근거 제외
