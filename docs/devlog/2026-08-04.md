## Decisions

- 한 Replacement Line의 Item은 모두 같은 색상 계열이며 Line 이름에는 색상명이 포함된다는 J의 운영 규칙을 색상 분류의 기준으로 사용한다.
- Item의 넓은 `semanticColor`만 사용하면 White와 Ivory, Navy와 Blue 같은 J의 Line 구분이 사라지므로 Line 이름을 우선하고 기존 팔레트와 Item HEX는 tile 색상 표현에 사용한다.
- Style Identity는 삭제하지 않되 색상보다 상위 navigation으로 사용하지 않고 선택한 색상의 Line 카드에 보조 label로 표시한다.
- 색상 선택 후 membership 목록을 한 번 더 보여 주는 것은 계보와 정보가 중복되므로 생략한다.
