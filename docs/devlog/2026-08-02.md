- 모든 양말의 기본 상하 위치를 28px로 설정하고 기존 150% 배율을 유지했다.
- `Outer-Coat`의 기본 배율을 150%로 설정했다.
- 옆에 분리한 `Top-T-shirts` 계열의 기본값을 좌우 -100px, 상하 64px, 배율 115%로 설정했다.

- `Outer-Vest`와 `Outer-Vest-made`의 기본 배율을 75%로 설정했다.
- category별 기본값과 분리 모드 회귀 테스트를 추가했다.

## Decisions - Outfit 기본 배치 보정

- 조끼 대표값은 production의 `Outer-Vest` 20개와 연결된 착장 relation 73개를 읽기 전용으로 확인해 결정했다. 조정 전 기록을 뜻하는 배율 0인 51개는 제외하고, 실제 조정값 22개(60~90%)의 중앙값인 75%를 사용했다.
- 세부 category 규칙을 일반 `Outer` 규칙보다 앞에 두어 코트와 조끼만 독립 기본 배율을 갖게 하고 다른 아우터에는 기존 90%를 유지했다.
- 저장된 착장별 위치·배율은 계속 category 기본값보다 우선한다.
