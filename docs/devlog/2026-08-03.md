## Work Completed

- Lookbook과 Calendar가 공유하는 착장 레이어를 110%로 확대했다.
- 아우터가 있을 때 우측에 분리되는 티셔츠의 새 기본 배율을 115%에서 90%로 변경했다.
- 착장 구성 버전을 v5로 올려 변경 전 미리보기와 새 구성 기준을 구분했다.

## Decisions

- 110%, 112%, 115% 비교 결과 차이는 작지만 100%보다는 개선이 분명했고, 잘림 위험이 가장 낮은 110%를 전체 표시 배율로 선택했다.
- 기존 데이터는 우측 티셔츠이면서 정확히 115%인 값만 과거 기본값으로 간주해 90%로 보정한다. 95%와 100% 등 다른 값은 사용자가 직접 조절한 값일 수 있으므로 보존한다.
- 확대는 개별 아이템 좌표를 다시 계산하지 않고 공용 3:4 착장 레이어에 적용해 Lookbook과 Calendar에서 동일한 결과를 유지한다.
