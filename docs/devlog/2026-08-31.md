# 2026-08-31 Closet Index Development Log

## Work Summary

Item 상세 화면에서 이미지로 이미 확인 가능한 색상 카테고리 대신, 기존 Outfit·Wear Log의 OK 관측으로 계산한 아이템별 착용 온도 범위를 보여주도록 변경했다.

## Work Completed

- Item 상세의 우측 기본 정보 가운데 칸을 `색상 카테고리`에서 `착용 온도`로 교체했다.
- 온도 근거가 있으면 `24 ~ 28°C` 형식으로 범위만 표시하고, 상세 화면에는 OK 관측 횟수를 함께 노출하지 않도록 했다.
- 온도 근거가 없는 아이템은 `근거 없음`으로 표시한다.
- Item 상세 시각 테스트에 온도 범위 표시, OK 관측 문구 미표시, 색상 카테고리 미표시 조건을 추가했다.
- CLOSET 상단 온도 요약이 제거된 현재 UI와 어긋나던 기존 테스트 기대값을 정리했다.
- 전체 테스트 647개 통과, TypeScript 타입 검사 통과, 프로덕션 빌드 통과를 확인했다.
- 인앱 브라우저에서 데스크톱과 390px 모바일 화면을 확인하고, CLOSET 목록에서 Item 상세로 이동했을 때 착용 온도 표시와 가로 넘침 없는 레이아웃을 확인했다.

## Decisions

- 온도는 새 DB 속성으로 저장하지 않고, CLOSET 온도 검색과 동일한 기존 계산 로직을 재사용한다.
- 색상 값 자체와 편집 기능은 유지하고 Item 상세의 요약 표시만 교체한다.
- 우측 3단 레이아웃을 유지해 드라이클리닝 같은 상태 배지 공간과 하단 사용 정보 영역을 변경하지 않는다.
- 요청한 정보 밀도에 맞춰 상세 화면에는 온도 범위만 표시한다.

## Current Status

변경은 로컬 코드에 완료되어 테스트와 빌드까지 통과했다. DB schema나 migration 변경은 없으며 아직 커밋, 푸시, 배포하지 않았다.

## Next Steps

- 실제 데이터에서 온도 근거가 없는 아이템의 `근거 없음` 표현을 확인한다.
- 필요하면 `착용 온도` 워딩만 별도 변경한다.
