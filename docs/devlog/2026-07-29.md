## Decisions

- 날씨 조회와 추천 적용을 분리했다. API 응답 직후 결과가 조용히 바뀌지 않게 하여 J가 예보를 확인하고 선택할 수 있도록 했다.
- 출발·귀가 시각은 1시간 단위 선택으로 제한했다. 기상청이 실제로 반환하지 않은 시각을 자동 반올림하거나 보간하지 않기 위해서다.
- 별도 서버 캐시 테이블 없이 같은 탭의 session storage를 먼저 사용한다. 현재 호출량에서는 구조와 비용을 단순하게 유지하는 편이 안전하다.
- API 실패는 기존 추천 기능의 실패로 취급하지 않는다. HOME의 수동 입력은 항상 독립된 fallback으로 유지한다.
- 원격 DB·Edge Function 설정은 이번 작업에서 변경하지 않았다.

## Decisions - Phase 2 W6 Wear Log 출처 추적

- Security Advisor에서 Phase 3 이미지 RPC 관련 경고가 없고, 예상한 Outfit RPC 3개의 authenticated `SECURITY DEFINER` 경고만 새로 생긴 것을 확인했다.
- Performance Advisor에는 Phase 3 적용을 중단할 새 경고가 없었다. 다른 앱·백업 schema와 기존 미사용 인덱스 안내는 범위 밖으로 유지했다.
- Function 관련 Vitest 3파일·8개 테스트와 TypeScript 검사를 통과한 뒤 `closet-item-image` version 1을 `ACTIVE`, `verify_jwt=true`로 배포했다.
- 인증 헤더 없는 production POST가 `401 UNAUTHORIZED_NO_AUTH_HEADER`로 거절되고 동일한 version 1 POST 401이 Edge 로그에 기록되는지 확인했다.
- 최종 기준선 Item 451개, Outfit 507개, 관계 2,401개, Wear Log 784개, 이미지 metadata 56개, ready 56개, Storage 57개가 적용 전과 같고 pending/error·고아 metadata·누락 Storage·잘못된 HEX가 모두 0개임을 확인했다.

## Decisions - Phase 3 production 계약 및 이미지 Function 적용

- P3-1 검증을 통과한 뒤에만 P3-3를 적용하고, 두 migration이 모두 정상인 경우에만 Function을 배포하는 단계별 중단 경계를 지켰다.
- Outfit RPC의 authenticated `SECURITY DEFINER` Advisor 경고는 relation 직접 INSERT를 열지 않고 transaction 함수 안에서 `auth.uid()`와 workspace membership을 재검증하기 위한 의도된 예외로 유지한다.
- 이미지 DB RPC는 브라우저에 노출하지 않고 service role 전용으로 유지하며, Edge Function이 caller-scoped client로 membership과 Item 접근권한을 확인한 뒤에만 호출한다.
- 실제 cutout 등록·교체는 metadata와 Storage를 변경하므로 비쓰기 배포 검증과 분리한다.
- 기존 다른 프로젝트의 Advisor 경고는 Phase 3 배포 범위를 넓혀 수정하지 않는다.

## Current Status - Phase 3 production 계약 및 이미지 Function 적용

P3-1과 P3-3 database 계약은 production에 적용됐고 기존 Closet 데이터와 이미지 무결성은 보존됐다. `closet-item-image` version 1은 `ACTIVE`, `verify_jwt=true`이며 무인증 호출 차단과 Edge 로그가 확인됐다. 실제 signed upload·finalize 경로는 production 쓰기를 발생시키므로 아직 호출하지 않았고, Phase 3 웹 앱 변경도 아직 commit·push·배포하지 않았다.

## Next Steps - Phase 3 production 계약 및 이미지 Function 적용

- J가 지정한 Item과 cutout 파일로 실제 등록 1회와 교체 1회를 승인할 경우 pending→ready 전환, 이전 ready 유지/교체, Storage 정리를 확인한다.
