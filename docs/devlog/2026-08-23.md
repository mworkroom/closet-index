## Decisions - Outfit 수정 저장 동선 및 중복 미리보기 정리

- 기존 착장의 선택 Item과 배치값은 그대로 불러오되, 추가 Item 탐색 목록만 Top으로 제한해 최초 이미지 요청 범위를 줄입니다.
- Item 추가·제거와 배치 조정 어느 위치에서도 저장할 수 있도록 수정 화면에만 고정 저장 액션을 사용합니다. 등록 화면은 기존의 마지막 저장 단계를 유지합니다.
- 중복 조합이 발견되면 같은 고정 액션의 문구를 `같은 조합으로 수정`으로 바꿔 기존 2단계 확인 동작을 유지합니다.
- 배치 조정기가 실시간 합성 결과와 개별 배치 제어를 함께 제공하므로 별도 실시간 미리보기는 중복 UI로 판단했습니다.
