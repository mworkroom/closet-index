## Decisions - Line 병합·보관·대표 Line

- 병합은 삭제가 아니라 source를 대표 Line에 연결된 archived 상태로 남긴다. 잘못 묶었던 기록을 다시 찾을 수 있고 대표 계보의 출처도 잃지 않기 위한 결정이다.
- 이미 다른 archived Line의 대표인 Line을 독립 보관하지 못하게 하고, 병합 시 기존 대표 참조를 새 target으로 한 단계에 다시 연결해 대표 chain이 길어지지 않게 했다.
- 독립 보관 Line만 직접 복원할 수 있고, 병합된 Line은 자동 분할 복원을 제공하지 않는다. membership·edge·start를 안전하게 역분배할 근거가 없기 때문이다.
- RPC는 `SECURITY DEFINER`의 빈 `search_path`, fully qualified relation, 함수 내부 workspace membership 검사와 `authenticated` 최소 실행 권한을 사용했다.
- production 변경은 별도 승인과 rollback 검증이 필요한 경계이므로 이번 작업에서는 read-only 데이터 감사와 migration·UI의 로컬 구현까지만 진행했다.
