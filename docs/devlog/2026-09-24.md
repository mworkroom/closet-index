## Work Completed - Outfit 착용 정보 표시

- Outfit의 Wear Log에서 체감이 `OK`인 출발·귀가 온도만 모아 관측 범위를 계산했다. 같은 통계에 최초 착용일도 추가했다.
- Outfit 상세 상단을 선호도·착용 온도·상태로 구성하고, 최초 착용일·마지막 착용·착용 횟수를 이미지 아래 세 칸으로 옮겼다.
- 포함된 Item 중 Retired가 있거나 연결된 Item을 찾을 수 없으면 `착용 불가능`, 모두 남아 있으면 `착용 가능`으로 표시했다.
- Outfit 그리드 카드에 관측 온도를 추가하고, 관측값이 없는 경우 `온도 근거 없음`을 표시했다. 상세 정보와 카드 글자 크기도 읽기 쉬운 수준으로 조정했다.
- 관련 통계·카드·상세 테스트를 추가했다. 전체 테스트 656개 통과, 타입 검사·빌드·CI 방식 Pages 산출물 검증 통과. 로컬 데모를 Chrome에서 2048px·1280px·390px 너비로 확인했고 가로 넘침과 콘솔 경고·오류는 없었다.

## Decisions - Outfit 착용 정보 표시

- 표시 온도에는 추천 계산용 ±2°C 여유 범위를 적용하지 않았다. `더움`·`추움` 기록도 OK 온도 범위에 섞지 않는다.
- 상태는 요청한 포함 Item의 Retired 여부를 기준으로 계산한다. 연결된 Item이 누락된 경우에는 착용 가능이라고 단정하지 않도록 불가능으로 표시한다.
- 새 데이터베이스 필드를 만들지 않고 기존 Wear Log와 Item 데이터에서 계산한다.
