## Decisions - Outfit clone client dead code cleanup

- 화면의 “이 착장으로 새로 만들기” 기능은 제거하지 않았다. 이 기능은 원본을 local draft로 복사한 뒤 새 UUID를 일반 create 계약으로 저장하므로 제거 대상인 server clone 경로와 다르다.
