# 2026-08-09 Closet Index Development Log

## Work Summary

Item 상세의 재구매·세탁 관리 영역에서 같은 정보가 여러 번 보이고 iPhone에서 관리 이력 버튼이 다음 줄로 밀리는 문제를 정리했다. 날짜를 짧게 통일하고, 이력 행을 한 줄 중심으로 재구성했다.

## Work Completed

- 재구매 기준일과 재구매 이력 날짜를 `M/D/YY` 형식으로 표시했다.
- 재구매 이력의 날짜와 수량을 `5/24/26 1개 구매`처럼 한 줄의 문장으로 합쳤다.
- 세탁 관리 영역의 중복 요약인 `현재 관리 방식`·`최근 관리일` 회색 패널을 제거했다.
- 관리 이력 제목을 `세탁 이력`으로 변경하고, 이력 행에서 반복 표시되던 관리 방식 문구를 제거했다.
- 각 관리 이력의 짧은 날짜와 `수정`·`삭제` 버튼을 같은 행에 배치했다.
- 모바일 CSS에서 이력 행을 강제로 1열로 바꾸던 규칙을 제거하고, 버튼이 줄바꿈하지 않도록 최소 폭과 nowrap 규칙을 추가했다.
- Item 상세와 Item Editor 테스트의 재구매 날짜 표시 기대값을 새 한 줄 형식으로 갱신하고, 두 건의 세탁 이력에 대한 날짜·버튼 배치 회귀 테스트를 추가했다.

## Decisions

- 날짜 값과 관리·재구매 데이터 모델은 변경하지 않고 기존 `formatMonthDayYear`를 사용해 표시 형식만 통일했다.
- 관리 방식은 수정 폼에서 여전히 변경할 수 있으므로, 읽기 화면의 반복 텍스트만 숨겼다.
- iPhone에서 버튼이 아래 줄로 내려가는 원인이 공통 모바일 이력 CSS였으므로 특정 화면의 임시 보정 대신 재구매·세탁 이력에 공통 레이아웃을 적용했다.
