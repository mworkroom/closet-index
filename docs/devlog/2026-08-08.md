- issue/mixed를 제거하지 않고 낮은 context tier에 유지했으며 Place·Transport 누락 시 N2 전체를 생략했다.
- `VITE_P5A_NORMAL_CONTEXT_N2`를 default false, development-only, production forced-false flag로 추가했다.
- W2 이후 final normal 배열에만 N2를 적용하고 Recent Purchase와 trial 배열을 보존했다.
- 정렬에 사용한 structured evidence를 HOME normal 카드의 한국어 한 줄 라벨로 전달했다.
- 요구된 21개 safety fixture와 카드 rendering 회귀를 추가했다.
- production SELECT-only 다섯 입력에서 top six, context 분포, 이동 수, issue/mixed visibility, candidate loss, W2 차이, inferred-return 영향과 longWalk 독립성을 확인했다.
- 인증 HOME에서 N2 off/on을 순차 비교하고 desktop 1280×720과 mobile 390×844 렌더링을 확인했다.

## Decisions - Safety-first N2 Disabled HOME Integration

- Thermal safety를 context 적합성보다 우선하므로 context tier는 같은 recommendation level 안에서만 작동한다.
- N1은 결과가 지나치게 희소해 rejected control로, Policy B는 rejected로, E2는 historical comparison으로 유지한다.
- W2는 Recent Purchase selected candidate이고 N2는 W2가 반환한 final normal만 후처리한다.
- Exact issue/mixed는 정보 손실을 피하기 위해 남기되 support·fallback·unknown 뒤에 둔다.
- Production 활성화는 이번 범위가 아니며 실제 deep-rank 재배열 경험을 확인한 뒤 별도 승인으로 진행한다.

## Current Status - Safety-first N2 Disabled HOME Integration

Nearby 30°C와 33°C의 exact high 후보는 normal rank 1이 됐고, 28°C에서는 exact high 다섯 장이 1–5위를 차지했다. Cinema + Car에서는 exact 세 장 뒤에 같은 Transport 세 장이 배치됐다. 모든 production 비교에서 caution exact는 high/possible 아래에 남았고 candidate loss, W2 difference, inferred-return ranking effect는 0이었다. 인증 desktop/mobile에 가로 overflow나 console warning/error가 없었다. Flag는 로컬 환경과 production 기본값 모두 false로 복구했다.

## Next Steps - Safety-first N2 Disabled HOME Integration

- Safety-first N2는 local opt-in QA를 완료했지만 별도 승인 전에는 production에서 활성화하지 않는다.
- 28°C와 30°C의 큰 deep-rank 재배열이 실제 탐색 경험에 적절한지 사용하면서 확인한다.
- HVAC와 Place Profile은 별도 Phase 5 후속 범위로 유지한다.
