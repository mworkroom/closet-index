## Work Summary - CLOSET 오늘 온도 탐색

CLOSET에서 특정 기온에 입을 수 있는 Item을 카테고리와 검색어로 함께 찾을 수 있도록, 기존 Outfit·Wear Log의 완성 착장 OK 관측을 Item별 온도 근거로 계산해 표시하고 필터링하는 기능을 추가했다.

## Work Completed - CLOSET 오늘 온도 탐색

- CLOSET 필터에 비워 둘 수 있는 `오늘 온도` 입력을 추가하고 기존 카테고리·색상·검색어·상태 필터와 함께 적용되도록 했다.
- Shoes와 `Dress` 또는 `Top + Bottom`을 갖춘 완성 착장만 온도 근거에 사용하고, Wear Log의 출발·귀가 체감이 `OK`인 실제 기온 관측만 수집하도록 했다.
- 각 Item 카드에 관측 최저·최고 기온을 기준으로 ±2°C를 확장한 범위와 OK 관측 수를 표시했다. 근거가 없으면 `온도 근거 없음`을 표시한다.
- 온도 필터가 켜지면 입력 기온 ±2°C 안에 실제 OK 관측이 있는 Item만 표시하고, 근거 없음과 다른 온도 근거의 제외 수를 별도로 안내한다.
- Outer·Top·Bottom·Dress뿐 아니라 Bags·Acc·Socks를 포함해 완성 착장에 들어간 모든 카테고리에 같은 근거 계산을 적용했다.
- 완성 착장 판정을 공통 helper로 분리해 기존 미착용 착장 추천과 CLOSET 온도 탐색이 같은 경계를 사용하도록 했다.
- 모든 카테고리 적용, 불완전·Error 착장 제외, 관측 사이 빈 온도 구간 제외, 온도·카테고리·검색어 조합과 필터 저장을 회귀 테스트로 추가했다.

## Decisions - CLOSET 오늘 온도 탐색

- 새 컬럼이나 migration을 만들지 않고 현재 Item·Outfit·Wear Log 관계를 화면에서 계산해 사용한다.
- 표시 범위는 관측 전체의 외곽 범위를 보여주되, 필터 판정은 범위 안 포함 여부가 아니라 목표 기온 ±2°C에 실제 OK 관측이 있는지로 판단한다. 예를 들어 10°C와 30°C 관측만 있을 때 중간인 20°C를 근거 있음으로 오판하지 않는다.
- 같은 Wear Log에서 출발·귀가 기온과 체감이 같으면 한 번의 관측으로 계산해 중복 집계를 피한다.
- 온도 근거는 과거 착용 사실이므로 현재 archived 된 완성 착장이나 retired 된 Item의 유효한 OK 관측도 보존한다. 다만 `Error` 착장과 구조적으로 불완전한 착장은 근거에서 제외한다.
- 온도 근거가 없는 Item은 부적합으로 해석하지 않고, 온도 미선택 상태의 카드와 온도 선택 상태의 요약에서 `온도 근거 없음`으로 명시한다.
