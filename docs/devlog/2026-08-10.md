# 2026-08-10 Closet Index Development Log

## Work Summary - 보조 가방 자동 배치

한 착장에 가방을 두 개 선택했을 때 같은 위치에 겹치던 문제를 해결했다. 첫 번째 가방은 기존 배치를 유지하고, 두 번째 가방은 아래쪽과 오른쪽으로 분리해 조금 작고 한 단계 뒤에 보이도록 했다.

## Work Completed - 보조 가방 자동 배치

- Outfit 합성 설정에 보조 가방 전용 슬롯을 추가했다.
- 착장의 아이템 순서를 기준으로 첫 번째와 두 번째 가방을 구분하고, 두 번째 가방에 보조 슬롯·88% 크기·하위 레이어를 자동 적용했다.
- 새 착장 작성과 기존 착장 수정의 배치 편집기에도 같은 기본값을 연결했다.
- 사용자가 저장한 위치·크기·레이어 값은 자동 기본값보다 우선하도록 유지했다.
- 두 가방의 기본 분리와 저장된 보조 가방 배치 보존을 검증하는 합성 테스트를 추가했다.

## Decisions - 보조 가방 자동 배치

- 기존 `itemPlacements`의 슬롯, 좌표, 크기, 레이어 구조만 재사용했다. 새로운 DB 열이나 migration은 필요하지 않다.
- 별도의 '보조 가방' 분류를 입력받지 않고 착장 내 가방 순서로 역할을 정해, 기존 데이터와 작성 흐름을 변경하지 않았다.
- 자동 배치는 시작점일 뿐이며, 기존 아이템별 배치 조정 기능으로 보조 가방만 따로 움직이거나 확대·축소할 수 있게 했다.
