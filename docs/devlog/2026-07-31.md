# 2026-07-31 Closet Index Development Log

## Work Summary

목에 두르는 숄과 이름은 비슷하지만 허리에 묶어 상의·하의 위에 겹치는 페이크숄을 독립적으로 표현하기 위해 `Acc-Waist` 카테고리와 전용 합성 규칙을 추가했다.

## Work Completed

- composition v4에 `main-waist` 슬롯과 `Acc-Waist` category rule을 추가했다.
- 900×1200 canvas에서 허리 액세서리를 600×260, z-index 55로 표시하도록 설정했다.
- 평평하게 펼친 누끼를 허리에 감긴 체감 비율로 보여주기 위해 `Acc-Waist`에만 `fill` 합성 방식을 허용했다.
- 브라우저 합성과 로컬 Sharp preview 합성이 같은 `visualWidth`·`visualHeight`·`fit` 설정을 사용하도록 확장했다.
- `Acc-Waist`를 Outfit 계절 판정과 최근 구매 대표 Item에서 제외하고 추천 온도 가중치를 보조 액세서리 수준으로 낮췄다.
- composition·계절·추천·로컬 합성 규칙 테스트를 추가했다.
- 첨부된 블랙 페이크숄 누끼로 900×1200 로컬 미리보기를 만들어 허리 체감 비율을 확인했다.

## Decisions

- category 식별자는 기존 형식과 맞춘 `Acc-Waist`를 사용한다.
- 실제 벨트와 허리에 묶는 숄을 역할이 같은 허리 액세서리로 확장할 수 있도록 제품명 대신 착용 위치를 category 기준으로 삼는다.
- 원본 누끼는 변경하지 않고 합성 단계에서만 비율을 조정한다.
- 레이어는 하의 30·상의 50보다 앞이고 아우터 60·가방 80보다 뒤인 55를 사용한다.
- production의 두 Item은 현재 `Acc-Neck`이지만, 배포 전 category를 먼저 변경하면 공개 앱에서 합성 규칙을 찾지 못하므로 코드 배포와 category 변경 순서를 분리한다.
