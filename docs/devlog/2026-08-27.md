## Decisions

- production cleanup은 edge 전환과 DDL을 하나의 transaction으로 묶는다. 필요한 lock을 5초 안에 확보하지 못하거나 preflight·의미 보존 검증이 하나라도 실패하면 전체 작업을 rollback한다.
- `IF EXISTS`와 `CASCADE`를 사용하지 않는다. 예상 object·dependency가 drift했다면 migration이 조용히 일부만 진행되지 않고 중단돼야 한다.
- source 두 column은 모든 edge가 독립 edge가 된 뒤 역사 보존용 nullable field로 남기지 않는다. 과거 판단은 검증된 local-only export가 보존하고 현재 graph의 source of truth는 `closet_replacement_line_edges` 하나로 유지한다.
- rollback은 schema와 개인 data를 분리한다. 추적 가능한 SQL에는 구조와 권한만 두고 production row는 Git ignore 자료로만 복구한다.
- `SECURITY DEFINER` 함수는 빈 `search_path`를 고정하고 public·anon 권한을 제거하며 authenticated·service_role의 의도한 execute만 명시한다.
- 운영 적용 전 단계에서는 read-only 재감사만 허용한다. 격리 검증 성공을 production 적용 완료로 표현하지 않는다.
