## 1. 선정 기준

제가 실제 Supabase 데이터에서 다음 기준을 함께 적용해 선정했다.

- 현재 계절인 여름에 실제로 입은 Outfit
- 23~31°C의 서로 다른 온도 구간
- 2026년에 최근 구매하거나 최근 착용한 Item
- 착용 횟수가 많아 온도 근거가 충분한 Outfit
- 같은 Item을 재사용해 필요한 누끼 수를 줄일 수 있는 조합
- 아우터, 오른쪽 상의, 양말, 목 액세서리, 원피스처럼 고정 슬롯의 예외를 검증할 조합

## 4. 파일 전달 방식

J가 UUID를 직접 파일명에 입력할 필요는 없다.

- J는 위의 정확한 Item명을 기준으로 누끼를 만든다.
- J가 전달하는 파일은 투명 배경 PNG 또는 WebP면 된다. 정확한 픽셀 크기와 WebP 최적화는 업로드 도구에서 처리한다.
- J가 Item을 캔버스 중앙에 놓거나 카테고리별 크기에 맞춰 축소할 필요는 없다. 투명 여백 제거와 카테고리별 배율은 자동 처리한다.
- 첫 파일을 받기 전에 제가 번호·Item명·UUID가 연결된 manifest와 local-only 폴더를 만든다.
- 파일명은 `001__Korshavn Cardigan.webp`처럼 사람이 확인할 수 있는 번호와 이름을 사용한다.
- 업로드 도구가 manifest를 통해 정확한 Item UUID와 연결한다.

이미지 파일과 개인 manifest는 Git에 포함하지 않는다.
